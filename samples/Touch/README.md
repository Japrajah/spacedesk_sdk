# Touch

Запустите `sd_touch.exe` без аргументов. После выбора хоста пример рисует
одним touch-контактом горизонтальную линию от 20% до 80% ширины изображения.
Для видимого результата откройте на хосте приложение, поддерживающее рисование касанием.

В [main.cpp](main.cpp) последовательность видна напрямую:

```cpp
client.touch(sample::Touch::Down, start_x, y);
client.touch(sample::Touch::Move, x, y);
client.touch(sample::Touch::Up, end_x, y);
```

Движение занимает секунду, события соединения обрабатываются 10 секунд.
Координаты относятся к полученному изображению, contact ID остаётся равным 0.
Обёртка вызывает `sd_client_send_touch` с флагами 3/1/5, как в классическом
Windows Viewer «Mouse local (as touch)». Это не относительный touchpad.
