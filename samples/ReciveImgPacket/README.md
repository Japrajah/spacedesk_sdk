# ReciveImgPacket

Запустите `sd_receive_image.exe` без аргументов. Пример подключается к выбранному
хосту, получает первый кадр и сохраняет его в `frame.bmp` в текущей папке.
Затем 10 секунд принимает FRAME-события и выводит размеры кадров.

[main.cpp](main.cpp) показывает `client.wait_frame()`, `client.poll()`
и `client.frame()`. `frame.pixels` — декодированный BGRA8 framebuffer,
которым владеет SDK. Используйте или копируйте его до следующего poll.

Название папки сохранено, но публичный API здесь отдаёт декодированные кадры,
не сырые сжатые сетевые пакеты. Существующий BMP не перезаписывается.
