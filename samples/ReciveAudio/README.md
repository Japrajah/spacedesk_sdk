# ReciveAudio

Запустите `sd_receive_audio.exe` без аргументов. После подключения дисплея
пример открывает аудиоканал и 10 секунд принимает звук хоста в `audio.wav`.

[main.cpp](main.cpp) показывает `client.start_audio(false)` и
`client.receive_audio(...)`. Замените false на true, чтобы также включить
локальное воспроизведение. Формат записи: 48000 Hz, stereo PCM16.

10 секунд — время цикла приёма, а не гарантированная длительность PCM:
сервер может прислать меньше данных. Файл создаётся при первом PCM-блоке;
если данных не было, пример сообщает об этом. Существующий WAV не перезаписывается.
При выходе сначала останавливается аудио, затем закрывается дисплей.
