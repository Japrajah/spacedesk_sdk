# SendKeyboard

Запустите `sd_send_keyboard.exe` без аргументов. После подключения
`client.key_press('A')` отправляет Windows VK_A: DOWN и UP.
Затем пример обрабатывает события соединения 10 секунд.

В [main.cpp](main.cpp) также показан `client.text(L"Hello from the SDK!")`
для отправки UTF-16 текста. Он закомментирован: замените им вызов key_press,
если нужен именно ввод текста. Ввод получает активное поле/приложение хоста.

Адрес, имя хоста и отправляемые данные задаются прямо в коде.
