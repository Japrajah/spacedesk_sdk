# MouseMove

Запустите `sd_mouse_move.exe` без аргументов. Пример найдёт хост, подключится,
отправит `client.mouse_move(100, 0)` — сдвиг вправо на 100 пикселей —
и будет обрабатывать соединение 10 секунд.

В [main.cpp](main.cpp) можно изменить адрес/имя хоста, смещение и длительность.
Рядом оставлен пример абсолютного перемещения:
`client.mouse_move(320, 240, true)`.

Абсолютные координаты заданы в пикселях полученного изображения.
По умолчанию SDK использует основной зеркалируемый монитор хоста;
для расширенного рабочего стола границы целевого монитора задаются через
`sd_client_set_mouse_target`. Этот короткий пример их автоматически не определяет.
